# Ririn Catering

Website statis (HTML, CSS, JavaScript). Buka `index.html` langsung di browser.

## Mengubah isi
- **js/config.js** — nama usaha, nomor WhatsApp, area, paket, menu, harga, ulasan.
  - Tambah menu: salin satu baris di `MENU_ITEMS`, ubah isinya.
  - Hapus menu: hapus barisnya.
- **images/** — ganti foto dengan nama file yang sama, atau ubah nama di config.js.
- **css/style.css** — warna di bagian paling atas (`:root`).

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file dan folder ini (index.html harus di paling atas).
3. Settings → Pages → Branch: main → / (root) → Save.
